## 💡 核心认知：被封了 6 个号后，我悟出的三条铁律

### 1. 积分扣分制：封号不是单一条件，而是“弱信号累加”
不要以为“某个参数不对就会立刻封号”。Anthropic 联合 Cloudflare、Stripe 和 Persona 建立的是一套**动态风险积分制（类似于驾照扣分）**：
- **单个轻微异常不致死**：比如偶尔网络断流一次、窗口尺寸不常见，系统可能只扣 5~10 分，账号依然处于放行状态；
- **跨维度冲突直接暴毙**：如果你代理走台湾出口（+0分），但 Mac 电脑名称叫“张三的MacBook”（+20分），国内 DNS 泄露（+20分），浏览器里装了篡改插件（+25分），输入框每次都是一瞬间整段粘贴长文（+15分） $\rightarrow$ **累加突破 80 分警戒线，立刻触发封禁！**
- **致命的延迟清算**：很多人以为“我今天折腾了一套新配置，登录成功了，用了两小时没事，说明我成了”。**大错特错！** 风控往往会把处决推迟到**首次账单付款复核**、**后台大模型异步跑图**或**周末凌晨**，让你误以为前面的伪造是有效的。

---

### 2. 为什么写防御探针、装防指纹插件去对抗，反而死得更快？
很多人被封后第一反应就是去装各种“防指纹插件”、“随机 Canvas 噪点”、“修改 User-Agent”。**这是最大的误区！**
- **自首式上报**：Anthropic 前端脚本不是傻子，它会主动做一致性检查。比如你用插件把 UA 伪装成 Windows，但你的 Chromium 底层接口依然如实汇报你是 Apple Silicon 芯片。脚本一比对，直接在后台给服务器发送：`ua_client_hints: "mismatch"`。**你装的插件等于主动向服务器递交自首报告！**
- **看不见的空白子网页（Iframe 夺舍）**：Cloudflare 脚本会在后台毫秒级生成一个 `about:blank` 的隐形子网页，在插件根本来不及注入的瞬间，直接提取子网页里原生干净的语言和硬件信息。我们解密抓包发现，主网页伪装得再好，子网页依然瞬间把真实的简体中文和 16GB 物理内存暴露得一干二净！
- **变异奇点效应**：全世界数亿正常用户都在使用标准的 Mac、iPhone、Windows。你装了各种防追踪扩展、随机加噪点，反而让你的设备指纹在全世界数据库里变成了**独一无二的怪物**，风控算法不抓你抓谁？

---

### 3. 一致性 > 伪装度：保持自然一致，难度远低于全端伪造
- **把 5 个端全部伪造成一致的假数据，神仙也做不到**：你得在网页端、手机端、桌面端、邮件端把时区、语言、TCP 握手包（JA4 指纹）、硬件签名全改得天衣无缝，只要有 1 个字节对不上，直接形成撕裂；
- **但让 5 个端全部指向一个“稳定真实的海外普通用户画像”，几乎不费力气**：
  保持官方原生客户端不改动、主机名改成通用英文、网络走纯净住宅代理并关掉 IPv6、通过官方支持的配置文件关闭遥测。**不伪装、不篡改，反而最安全。**

## 🛠️ 怎么防封？拿真金白银换来的最接地气实操指南

既然知道它在查什么，我们**坚决不搞花里胡哨的指纹插件**，只做**符合常理的干净自洽配置**：

### 1. 电脑名字脱敏（防桌面端 D-01 探针）
在 Mac 终端里运行下面这行命令，把中文名字改成普通的英文名：
```bash
sudo scutil --set ComputerName "macbook-air"
sudo scutil --set HostName "macbook-air"
sudo scutil --set LocalHostName "macbook-air"
```

### 2. 彻底关掉 IPv6（防手机和电脑 IPv6 穿透 M-03 探针）
国内运营商的 IPv6 是最大元凶，运行以下命令彻底关闭无线网的 IPv6：
```bash
sudo networksetup -setv6off "Wi-Fi"
```

### 3. Chrome 保持 0 插件，建一个干净的专用 Profile（防 W-01、W-06 探针）
- 不要在日常混杂各种国内扩展的浏览器里登录 Claude；
- 点击 Chrome 头像 $\rightarrow$ **添加新个人资料** $\rightarrow$ **不装任何防关联插件、不装脚本**；
- 原生干净的 Chrome 在风控眼里反而是信誉度最高的。

### 4. 桌面端用官方允许的方式关闭遥测（防 D-05 探针）
**不要用第三方工具去 Hook 桌面端！** 直接打开官方支持的配置文件：  
`~/Library/Application Support/Claude/claude_desktop_config.json`  
写入以下内容，官方合规关闭后台数据采集：
```json
{
  "disableNonessentialTelemetry": true,
  "disableEssentialTelemetry": true,
  "disableNonessentialServices": true,
  "disableAutoUpdates": true,
  "modelCatalogEnabled": false,
  "skipWebFetchPreflight": true
}
```

### 5. 换号重生：最省事的办法是新建一个 Mac 系统用户
如果你的号已经被封过，单清 Cookie 根本逃不脱 `ant-did`、Keychain 和 Secure Enclave 硬件芯片的图谱连坐。  
**最干净彻底的物理隔离法**：
1. 打开 Mac【系统设置】 $\rightarrow$ 【用户与群组】 $\rightarrow$ **新建一个标准用户（例如起名叫 Work）**；
2. 登录进这个全新系统用户，系统会自动生成完全隔离的 Keychain、全新的安全芯片上下文和全新的 Chrome 配置；
3. **旧的充值过被封账号的 Apple ID 绝对不要再给新号充值**（`original_transaction_id` 已经进黑名单），新号使用全新美区 Apple ID + 官网礼品卡充值。
