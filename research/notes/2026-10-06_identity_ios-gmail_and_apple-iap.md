## 1. 常见封号死因尸检报告 (Postmortem)

大量的 Claude 封号并非发生在「使用过程中」，而是在「注册瞬间」或「绑卡扣款次日」被系统批量处理。风控审计的核心日志往往命中以下致命红线：

```
[Trigger 1: Registration Phase]
- 邮箱域名：aliyun.com / qiye.aliyun.com / dingtalk.com -> 命中高危批量注册黑名单。
- 网络环境：国内双栈宽带泄漏真实公网 IPv6 (240e:*) -> 握手直连，秒封。
- 浏览器指纹：日常 Chrome Profile 登录了国内 Google 账号，Gaia ID 被跨站标记。

[Trigger 2: Payment Phase (Stripe 网页端)]
- 发卡行 BIN：国内招行/工行 Visa/Mastercard 或 Depay/OneKey 虚拟卡 -> 标记为离岸高危卡。
- 账单地址：IP 位于洛杉矶，账单地址乱填特拉华州，发卡行为中国或立陶宛 -> AVS 评分不及格。
- 拒付风险：Stripe Radar 评估风险指数 > 75 -> 拦截付款或次日凌晨自动封禁账号。
```

## 2. 邮箱信用金字塔：为什么必须淘汰阿里企业邮与 Outlook？

Anthropic 对注册邮箱域名的信誉等级实行严格分级：

```
                    ▲
                   / \     [Tier 1: 顶级白名单]
                  /   \    原生个人 Gmail / iCloud Mail
                 /─────\   通过 Google SSO 授权登录，天然免审
                /       \
               /         \  [Tier 2: 中等信誉]
              /           \ 知名海外企业邮箱 / 历史悠久的 Yahoo/Hotmail (老号)
             /─────────────\
            /               \ [Tier 3: 高危审查]
           /                 \ 批量 Outlook / ProtonMail / 域名企业邮 (新解析)
          /───────────────────\
         /                     \ [Tier 4: 即刻封杀]
        /                       \ 阿里企业邮 / 163 / QQ / 10minutemail 等临时邮箱
       └─────────────────────────┘
```

- **阿里企业邮的致命破绽**：其 MX 记录指向阿里云中国大陆服务器，域名注册商通常为万网（Alibaba Cloud Computing），在国际反垃圾与欺诈库中具有极高的中国境内特征。
- **Outlook/Hotmail 的泛滥滥用**：黑灰产常年利用脚本批量生成廉价 Outlook 账号，导致微软邮箱在 Anthropic 的初始风控评分中被大幅扣分，极易触发人机验证死循环。
- **最佳实践**：**100% 采用全新、未绑定国内手机号的原生 Gmail 账号**。

## 3. 苹果 iOS 原生通道免短信创建纯净 Gmail 实操手册

很多国内用户无法注册 Gmail，是因为在网页端注册时被强制要求验证手机号，而输入 `+86` 手机号后提示「此电话号码无法用于进行验证」。

### 原理解析：为什么 iOS 能免短信注册？
Apple 设备的 **Secure Enclave** 硬件隔离芯片与 iOS 系统底层为 Google 提供了极高置信度的设备完整性证明（Device Integrity & Attestation）。在原生系统设置中发起注册时，Google 的风险引擎会大幅放宽风控阈值，**允许用户直接跳过手机号绑定**！

### 完整图文级实操流程（耗时 2 分钟）

#### 准备工作
- 一台装有正常 iOS 系统的 iPhone 或 iPad。
- iPhone 连接 Wi-Fi，且网络已接入**台湾中华电信 HiNet 住宅节点**（或干净美区住宅节点）。

#### 步骤一：进入系统邮件配置
1. 打开 iPhone **「设置」 (Settings)**。
2. 下滑找到并点击 **「邮件」 (Mail)** -> **「账户」 (Accounts)**。
3. 点击 **「添加账户」 (Add Account)**。
4. 在服务提供商列表中选择 **「Google」**。

#### 步骤二：发起个人账号创建
1. 系统会弹出网页授权弹窗（`accounts.google.com`），点击 **「创建账号」 (Create account)**。
2. 务必选择 **「用于个人用途」 (For my personal use)**。
3. 填写姓名（建议使用英文字母，如 `Alex` / `Chen`）。
4. 填写出生日期（**年份务必选择 2000 年以前，保证年龄大于 22 岁**），选择性别。

#### 步骤三：挑选邮箱地址与密码
1. 自定义一个看似真人的 Gmail 地址（如 `alexpc.tw88@gmail.com`）。
2. 设置高强度密码。

#### 步骤四：一键跳过手机号绑定（关键步骤！）
1. 下一步页面标题会显示：**「添加电话号码？」 (Add phone number?)**。
2. **千万不要输入任何手机号！** 直接滑到页面左下角或最底部。
3. 点击显眼的 **「跳过」 (Skip)** 按钮！
4. 在随后的「添加辅助邮箱」页面，同样点击 **「跳过」 (Skip)**。
5. 点击「同意」隐私与服务条款。
6. 返回设置页面后，关闭通讯录/日历同步，点击保存即可。

恭喜！你已拥有一枚 **0 污染、0 绑定国内信息、拥有 Google 顶级硬件信用背书的极品 Gmail**！

## 4. 手机号验证避坑：实体运营商 vs 虚拟 VOIP 号码

在通过 Google SSO 首次登录 Claude 时，部分情况下若 IP 信誉不够极致，仍可能要求验证手机号：

### 绝对不能使用的号码类型
- ❌ **Google Voice / TextNow / Dingtone / Skype**：这类号码在国际运营商数据库中明确标记为 `VOIP / Virtual`，Anthropic 系统级拦截，提交即报错 `Phone number type not supported`。
- ❌ **接码平台上的劣质虚拟号**：已被成千上万个恶意账号重复利用，即使接码成功，也会在 24 小时内因同号关联被封。

### 推荐的高存活度解决方案
1. **海外原生实体 SIM / eSIM**：
   - 英国 giffgaff 实体卡（国内可漫游收短信，0 月租保号）。
   - 美国 Tello / Ultra Mobile PayGo 实体卡。
   - 台湾中华电信 / 远传电信预付卡。
2. **优质接码平台 (选择 Real Carrier 物理卡筛选)**：
   - 使用 SMS-Activate 等平台时，**必须勾选筛选实体运营商（Physical SIM / Non-VOIP）**，避免虚拟号码池。

## 5. Claude Pro 订阅风控：Stripe 网页端陷阱与 Apple IAP 终极解

### 为什么网页端 Stripe 订阅是封号重灾区？
网页端订阅通过 Stripe 处理，其内置的 Stripe Radar 会对交易执行极其严苛的多维风控：
1. **发卡行地区 (BIN Country)**：中国大陆银行发行的双币信用卡（即使是 Visa/Mastercard）直接被识别为离岸非服务区，高概率砍单。
2. **虚拟卡标记**：市面上的 Depay、Dupay、OneKey、WildCard 等虚拟预付卡，其 BIN 码号段已被广泛列为高拒付风险。
3. **地址验证 (AVS)**：持卡人账单地址必须与发卡行系统记录 100% 匹配。

### 终极安全解法：Apple In-App Purchase (IAP) 闭环体系

苹果生态的内置购买（IAP）是目前对抗 Claude 订阅风控**成功率最高、存活率近乎 100%** 的方案：

```

│                        Apple 官方礼品卡充值流程                        │
│   正规国内信用卡 -> Amazon.com / Apple 官网购买美区/台区 Apple 官方 Gift Card  │
│                                    │                                   │
│                                    ▼                                   │
│                  兑换充值至 美区 / 台区 Apple ID 账户余额                │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                         iOS Claude 客户端 IAP 扣款                     │
│  - iPhone 连接台湾 HiNet 住宅节点                                      │
│  - 打开官方 Claude iOS App，使用纯净 Gmail 登录                         │
│  - 点击 Upgrade to Claude Pro -> 唤起 Apple 官方面容/密码支付           │
│  - 资金直接从 Apple ID 余额扣除                                         │
```

#### 实施步骤：
1. 准备一个美区或台区 Apple ID（可自行免费注册）。
2. 在美亚（Amazon.com）或支付宝「出境-折扣礼品卡」购买对应面额的 Apple Gift Card 兑换码。
3. 在 App Store 兑换充值，使 Apple ID 拥有 \$20 或 NT\$650 以上余额。
4. 在 iPhone 上切换至该 Apple ID，在 App Store 下载官方 **Claude by Anthropic** 应用。
5. 在台湾 HiNet 节点环境下打开 Claude App，登录您的零污染 Gmail。
6. 点击 Settings -> Upgrade to Pro，直接使用 Apple ID 余额订阅。
7. **全链路完成，无需任何外币信用卡，100% 规避 Stripe 砍单与封号！**
