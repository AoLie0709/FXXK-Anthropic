# 06 · 研究路线与方法

> 本项目是长期研究，而不是一次性配置。这里记录**研究方法、开放问题和下一步方向**。

---

## 1. 研究方法

1. **区分事实、推断与传言**：每条结论标注来源——实测 / 官方文档 / 情报检索 / 社区经验。
2. **控制变量**：一次只改变一个因素，记录前后差异。
3. **可复现**：结论配套检测脚本或检测步骤，放入 `tools/`。
4. **情报持续采集**：通过 Tavily 多 Key 流水线定期检索最新风控动态（`tools/scripts/tavily_intel_gatherer.py`）。
5. **定期回顾**：方案会过时，原则也可能需要修正；每次重大事件后回顾 `docs/`。

> ⚠️ 网上流传的「存活率 xx%」「100% 不封」之类数字基本不可验证，本项目不采信、不复述。

## 4. 产出归档约定

| 产出类型 | 位置 | 命名 |
| :--- | :--- | :--- |
| 方向性原则 | `docs/` | 编号前缀，长期维护 |

| 情报报告 | `research/intel/` | 工具生成，可按日期归档 |
